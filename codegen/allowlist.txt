# Generated-op allowlist: one `<shard> <aten-op-name>` per line.
# <shard> groups ops into one C++/Racket translation unit each;
# <aten-op-name> is the full schema name (with overload, e.g.
# `sum.dim_IntList`) from codegen/aten/native_functions.yaml.
#
# The linalg family doubles as the golden-equivalence proof: the
# generated tr_gen_* ops are asserted bit-identical to the hand-written
# tr_* ops in cpp/tests/torchrkt/generated_golden_test.cpp. The
# hand-written family stays authoritative in v2.

linalg matmul
linalg mm
linalg mv
linalg dot

# shape ops exercise the IntArrayRef and TensorList marshalling paths
# end to end (golden-tested against the hand-written twins like linalg).
shape reshape
shape cat
shape narrow

# hand-binds tr_gen_narrow for the repr summarizer (require-cycle

shape select.int

# --- tranche 2 (#3): the Conv-MNIST op closure ----------------------------

# conv + pooling. conv2d exercises the optional-Tensor (bias) marshalling;
# avg_pool2d the optional-int64 (divisor_override).
conv conv2d
conv max_pool2d
conv avg_pool2d
conv adaptive_avg_pool2d

# loss primitives. weight is optional; targets are int64 (the to-dtype
# bridge); reduction is the ATen enum int (Mean=1). Full dtype work is v3.
loss nll_loss
loss cross_entropy_loss

# dim-wise reductions: int[1]? dim (optional-int-array) + ScalarType? dtype
# (optional-dtype, always nullopt in float32-only v2).
reduce sum.dim_IntList
reduce mean.dim
