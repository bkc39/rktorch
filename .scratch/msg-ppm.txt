vision: image-grid and write-ppm, sample grids without a dependency (#155)

image-grid lays an [N C H W] batch out as one image on its own device with
torchvision's make_grid layout (columns across, padding around every image,
one channel tripled), so the twin pins it cell for cell. write-ppm writes a
[3 H W] tensor as binary P6: a float image quantized the way save_image
does, with #:range naming the values that map to 0 and 255, so the [-1, 1]
datasets pass '(-1 1); a uint8 image is written as it is. The uint8 export
already moves to the CPU and makes the data contiguous, so the quantization
and the permute stay on the device.

Pulled forward from #84 leg 4 for the DCGAN and VAE grids of #152; the
diffusion sampler reuses it. The twin imports torchvision where the Python
has it and otherwise runs make_grid's own algorithm, since the CUDA parity
shell carries torch-bin alone.
