review: make_grid returns one image unpadded, and three smaller fixes

`image-grid` padded a batch of one, where `make_grid` returns that image
as it is; the twin's fallback gained the same early return and the
cross-test checks a seeded singleton against it. The rest come from the
same review:

- `write-ppm` accepted a boolean image and then failed inside ATen,
  which has no subtraction for that dtype; `image/c` refuses it.
- 10-dcgan's `train-step` built its two loss targets on the default
  device while everything else followed the `device` it was given, so a
  direct call on a GPU model mixed devices.
- The write-ppm cross-check compared quantized bytes exactly while the
  values beside it are compared with `tol`, so a difference between two
  torch builds near a half would fail it by one byte. It now allows the
  one byte, and checks the length separately.
