# rktorch v1 — task list

Design rationale: `docs/design/v1-codegen-nn.md`. Goal: **tensor tranche +
autograd + one Linear/MLP, validated against PyTorch.** Hand-written `extern "C"`
shim (no codegen in v1). CPU only.

## Phase 1 — Tensor tranche (no nn decision needed)
- [x] Widen `cpp/src/torchrkt/` + `cpp/include/torchrkt/c_api/` (split per
      family: `creation/shape_ops/elementwise/reduce/linalg`, shared
      boundary helpers in `src/torchrkt/detail/op_call.hpp`):
  - [x] creation: `zeros ones full arange eye randn`, `tensor` (flat vec + shape)
  - [x] shape: `reshape view transpose permute squeeze unsqueeze cat stack`
  - [x] elementwise: `add sub mul div neg exp log sqrt pow relu sigmoid tanh`
  - [x] reductions: `sum mean max min argmax softmax log_softmax`
  - [x] linalg: `matmul mm mv dot`
  - [x] out: `tensor->list`/`->vector`, `item`, `shape`/`numel`, `to-dtype`
- [x] Raw FFI + facade: `torchrkt/foreign/raw/{creation,shape-ops,elementwise,reduce,linalg}.rkt`,
      `foreign/tensor-ops.rkt` (keep handle + finalizer + `last_error`);
      colliding names (`exp log sqrt max min argmax`) dispatch to
      racket/base / racket/list on non-tensors
- [x] gtest goldens for representative ops (`ops_test.cpp`)
- [x] example pairs: `01-arith`, `02-matmul` (+ parity cross-test entries)
